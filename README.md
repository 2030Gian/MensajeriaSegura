# 🔒 Secure Message UX - Simulación P2P (Alice & Bob)

Este proyecto es una aplicación de escritorio en Java que implementa una interfaz de usuario (UX) de **Mensajería Segura**. El sistema está diseñado para simular una comunicación cifrada entre dos partes.

Para probar el sistema, es necesario ejecutar la aplicación **dos veces simultáneamente** para crear dos clientes distintos: **Alice** y **Bob**. Cada ejecución abrirá su propia "Ventana de Mensaje Seguro".

---

## 📋 Requisitos del Sistema

Antes de comenzar, verifica que tu entorno de desarrollo cumpla con los siguientes requisitos estrictos:

1.  **Java JDK 17** (LTS): Requerido para ejecutar las nuevas características del lenguaje.
2.  **Apache Maven 3.8+**: Para la gestión de dependencias y construcción.
