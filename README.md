# Proyecto de Chat P2P (Alice & Bob)

Este proyecto implementa una interfaz de usuario (UX) en Java para simular una comunicación entre dos clientes (Alice y Bob). El sistema permite ejecutar múltiples instancias para probar la interacción en tiempo real.

## 📋 Requisitos Previos

Asegúrate de tener instalado y configurado lo siguiente en tu sistema:

* **Java Development Kit (JDK):** Versión 17.
* **Apache Maven:** Versión 3.6 o superior.

Puedes verificar tus versiones ejecutando:
```bash
java -version
mvn -version
